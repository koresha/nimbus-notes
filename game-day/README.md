# Game Day (séance 8)

Incident **fictif** : un bulletin annonce qu'une bibliothèque est compromise, et une image inconnue est apparue dans le registre.

| Fichier | Rôle |
|---|---|
| `bulletin-FICTIF.md` | Le bulletin de sécurité (fictif) de la Banque Azur |
| `preparer-game-day.sh` | Met en place la situation dans votre registre local |
| `modele-post-mortem.md` | Modèle d'une page à remplir à la fin |

Lancement : `./game-day/preparer-game-day.sh`, puis suivez la fiche Game-Day.html.
